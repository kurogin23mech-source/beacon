# Beacon Note

> ユーザーが「メモして」「覚えておいて」と言ったとき、または自分がコンパクション後に知っておくべき重要な文脈を見つけたときに実行する。

## 前提条件チェック

Bash ツールで以下を実行:
```bash
test -f .beacon/project.json && echo "OK" || echo "NO_BEACON"
```
- `NO_BEACON` の場合、このSkillは何もせず終了する。

## 実行

記録内容と文脈を整理して Bash ツールで実行:

```bash
beacon note "<記録するテキスト>" [--context "<文脈ラベル>"]
```

### テキストの書き方
- 1〜2文で完結する内容にする
- 「なぜ重要か」が自明でない場合は `--context` でラベルをつける
- 例: `beacon note "gcloudのactiveアカウントはPEのSAになりがち。デプロイ前に確認" --context "デプロイ手順"`

### メモすべき内容の例
- ユーザーが「メモして」「覚えておいて」と明示した内容
- 設計の方針変更・決定事項（docにするほどではないが忘れると困るもの）
- 次のコンパクション後に知っておかないと困るコンテキスト
- セッション中に発見したハマりポイント・注意事項

### メモしなくていい内容
- 進捗状況（beacon status で見える）
- コミット内容（git log で見える）
- タスク一覧（beacon task list で見える）

## 制約

- 書き込みは `beacon note` コマンド経由のみ
- 1回の呼び出しで1件のみ記録する（複数ある場合は複数回呼ぶ）
