v3 の変更
  • トンマナを Web UI に統一: void 背景 / 緑アクセント + グロー / 走査線 / モノスペース (IBM Plex Mono)。カードだけ浮かないよう Web UI と同じトークンを使う。
  • 状態を 3 つに整理: 作業中 (手が動いている) / 確認待ち (質問・選択肢・許可で停止 = あなた待ち) / 待機中 (手待ち)。曖昧だった「稼働中 / 最近動いた」を廃止。停止 (dead) は淡色で従来どおり。
  • 確認待ちを要対応色に: 橙 (Web UI の --waiting) の塗り札 + 鼓動するドットで、止まって待っているセッションが一目で分かる。データは activity_kind=wait + 待機内容 (「Claude needs your permission」等) から判定。
  • 飛ぶボタンを廃止 → カードクリックで端末へ飛ぶ: ボタン分の場所を無くしカードを更に小さく。hover で緑グロー + 「端末へ →」の手掛かり。「送る」だけ従ボタンで残し、クリックは stopPropagation でカード飛びと分離。別マシン/pid無/未対応端末は非 jumpable (クリック不可)。
  • 折り返し維持: 文字は省略で隠さず折り返す。親子はレール + 爪のエッジのみ (語なし)。
